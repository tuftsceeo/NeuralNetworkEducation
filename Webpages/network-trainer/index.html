Challenge

Build a windmill driven by a single motor, and use a joystick to simulate wind — the harder you push it, the faster the windmill spins.

Think Like a programmer

How does the weight (slope) control how much the joystick affects the windmill's speed?

Think Like an engineer

Once the windmill only spins one way, what should "wind" pushing the wrong direction actually do?

Getting Started

  1. Level 1 — Slope: connect the joystick as an input and the windmill's motor as an output. Adjust the weight until moving the joystick changes the spin speed.
  2. Level 2 — Bias: add a bias so the windmill spins at a constant idle speed when the joystick is at 0, then speeds up as you push it.
  3. Level 3 — Activation: add an activation function (try ReLU) so the windmill only turns clockwise — pushing the joystick backward should simply stop it, not reverse it.

Challenge

Build a spinning display with a yellow side and a green side, and control its motion with a color sensor facing the spinning part.

Think Like a data scientist

How do the weight and bias work together to set both the direction and the baseline speed?

Think Like a programmer

Why does the color sensor's hue value, not just "it's yellow" or "it's green," matter to the network?

Getting Started

  1. Level 1 — Weight & bias: get the motor spinning at one constant speed with no sensor input yet — that's pure bias, no weight needed.
  2. Level 2 — Direction: add yellow and green sides plus a color sensor. Using hue as the input (roughly: above 65 = green, below = yellow), set the weight and bias so green spins one direction and yellow spins the other.
  3. Level 3 — Custom activation: instead of switching direction, build a custom activation where values below 0 become a small number (slow) and values above 0 become a larger number (fast), so green speeds up and yellow slows down.

Challenge

Build a plant that dances (motors spinning) during the day and goes still at night, using a color sensor to tell day from night.

Think Like a data scientist

Why does reflection work better than hue for telling yellow (day) apart from blue (night) here?

Think Like an engineer

What does subtracting the blue reading, then applying ReLU, actually do to a night-time reading?

Getting Started

  1. Connect your color sensor as input and the motor(s) as output, reading reflection (yellow reads higher than blue).
  2. Set the hidden layer to subtract the blue reading (plus a small margin) from the input, then apply ReLU — this clamps any night-time (blue) value to exactly 0.
  3. Test in daylight (yellow) vs. darkness (blue) and confirm the plant only dances when yellow is detected.

Challenge

Build a revolving door that starts spinning at a constant speed whenever something approaches the color sensor.

Think Like an engineer

Why might this task need more than one neuron, instead of just one?

Think Like a scientist

Sigmoid outputs are never quite 0 — what does that mean for a door that's supposed to be completely still?

Getting Started

  1. Connect your color sensor as input and the door's motor as output. Try a Sigmoid activation — it gives a clean, bounded on/off-style response.
  2. Since Sigmoid never actually reaches 0, subtract a small offset from its output so "nothing approaching" reads as truly stopped, not just slow.
  3. Bonus ⭐: swap in a different activation function (ReLU, Tanh, Softplus) and adjust the other weights/biases until you get the same door behavior — compare how each one gets there differently.

Think Like a scientist

Why does Sigmoid work well here compared to leaving the output unclamped?

Think Like an engineer

Once the umbrella is fully open, what should make it stop — even if it's still raining?

Getting Started

  1. Connect your rain sensor (color sensor) as input and the umbrella's motor as output, using Sigmoid so speed stays within a consistent range.
  2. Add a second color sensor that detects the umbrella's own position (open vs. closed).
  3. Combine both inputs into one output so the "raining" signal is overruled once the position sensor shows fully open — work out weights/biases so one input can cancel out the other.

Activation functions

An activation function is applied to each neuron's output before it becomes usable downstream. It introduces non-linearity so the network can learn complex patterns. One activation function is shared by every neuron.

None No transformation. Output passes through unchanged (identity).
ReLU Sets negative values to zero. Fast and widely used in deep learning.
Sigmoid Squashes output to (0, 1). Good for probability outputs.
Tanh Squashes output to (−1, 1). Zero-centred, often better than Sigmoid.
Softplus Smooth approximation of ReLU. Always positive with no hard zero.
Custom Define your own f(x), optionally as separate pieces over different ranges of x.
